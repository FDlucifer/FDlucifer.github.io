域认证与权限关系

先记录当前身份、持有的凭据种类和能访问的接口，再读目录对象和证书字段。原记录保留 NTLM 禁用、PKINIT 失败、时钟误差与清理任务回滚等实际问题。

  • Kerberos 与服务权限 对照密码、哈希、证书、TGT 与服务票据。
  • ACL 与委派 对照组成员、Shadow Credentials、gMSA、KCD 与 RBCD。
  • ADCS 模板与 CA 对照注册权限、SAN、颁发审批与认证映射。
  • ESC13 与多阶段域权限 沿 Mist 的账户和证书转换读完整长链。

工具与凭据材料可配合 crackmapexec终极指南、windows下hashcat利用GPU显卡性能破解密码、LaZagne—全平台多功能密码恢复工具 查阅。

二进制、浏览器与内核

从保护检查、输入边界、泄漏和对象生命周期开始，按原环境核对架构、libc、编译提交与 gadget 副作用。

  • 栈与相邻对象 保留偏移、函数指针、ARM 调用约定与 Egghunter。
  • 格式化字符串 逐层追踪 PIE、Canary 与 libc。
  • ROP / SROP / JOP 对照页权限、输入分段和寄存器控制。
  • 堆与分配器 跟踪释放、重分配、别名指针与 tcache。
  • V8 与 内核接口 保留构建、调试和最终原语。
  • 认证逆向与 Salsa20 对照控制流、加密参数和字节序。

方法与延伸研究见 PWN-LINUX技巧总结、pwn逆向资源以及各种poc收录、Jump-Oriented编程-[JOP]-一种新的代码复用攻击、JavaScript-JIT引擎逻辑漏洞利用、v8中简单bug的复杂漏洞。
