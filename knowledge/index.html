原实验中的版本、目标地址、回连地址、文件路径、时钟、账户权限和二进制布局决定载荷的适用范围。阅读时可先查索引，再对照同一案例的输入、输出和最后脚本。

Web安全

  • PHP 运行时、缓存与执行边界 · 3 个来源，67 个代码块。php_again 的 system_id 和 Zend Extension 差异决定缓存能否被目标加载，编译参数属于证据的一部分。
  • 认证状态、JWT 与访问控制 · 7 个来源，187 个代码块。Academy、Previse 的服务端权限判断与页面跳转各有边界，页面可见性和操作权限需要分别验证。
  • SSRF、协议转换与内部管理面 · 3 个来源，116 个代码块。AdmirerToo 的 OpenTSDB 指标名称会影响后续执行是否真正到达目标函数。
  • Drupal 入口与本地权限衔接 · 3 个来源，36 个代码块。Armageddon 的 snap 分支保留原脚本失败后对载荷内容的处理。
  • 调试协议与服务暴露 · 3 个来源，62 个代码块。Backdoor 先用文件读取定位进程，再连接 gdbserver。
  • CMS 管理功能与历史执行链 · 5 个来源，70 个代码块。Blunder、GoldenEye 分别记录 Bludit 和 Moodle 的既有执行路线。
  • 模板注入与多语言表达式 · 5 个来源，116 个代码块。Bolt 与 Doctor 的配置、密钥和备份数据不同，读取与执行阶段需要沿各自证据核对。
  • XML 外部实体与二次解释 · 1 个来源，15 个代码块。Base64 和 URL 编码影响加号等字符在请求与响应中的传输。
  • 反序列化、对象生命周期与加载器 · 9 个来源，162 个代码块。Feline、Logforge、Time 和 Ophiuchi 分别依赖会话文件、JNDI、类型绑定和 YAML 加载。
  • SQL、NoSQL、HQL 与 XPath 注入 · 11 个来源，224 个代码块。Ezpentest 的 BIGINT 错误与 Mango 的 MongoDB 运算符采用不同判断条件。
  • 浏览器上下文与跨权限操作 · 2 个来源，75 个代码块。Crossfit 记录读取页面、构造操作与后台任务，后续还有独立的密钥分析。
  • WordPress 插件与管理权限 · 5 个来源，92 个代码块。Phoenix 的盲注与上传属于两个插件，OTP 和 rsync 是后续系统阶段。
  • 中间件请求解析与管理接口 · 4 个来源，72 个代码块。pWnOS 与 GoatseLinux 的管理接口保留文件读取和替代认证路径。
  • 文件写入、上传验证与后续解析 · 6 个来源，103 个代码块。Drunk Admin 与 In Plain Sight 的图像处理保留双后缀及内容检测。
  • 路径归一化、文件包含与日志内容 · 5 个来源，100 个代码块。Pikaboo 连接 alias、文件包含、FTP 日志和 Perl open。

系统安全

  • Windows 服务权限与执行上下文 · 7 个来源，188 个代码块。Acute、Reel2 的 PowerShell 会话限制与命令运行账户是不同条件。
  • Linux 权限、Capabilities 与周期任务 · 10 个来源，167 个代码块。Cap 的 Python capabilities、NullByte 的 PATH 和 Pit 的目录 ACL 属于不同权限机制。
  • DNS、NFS、邮件与多主机信任 · 5 个来源，175 个代码块。Vulnix 的 UID 与 root_squash、Dynstr 的 PTR 与更新密钥各有明确配置条件。
  • 数据库权限、UDF 与动态库加载 · 3 个来源，63 个代码块。Raven 两篇分别保留 PHPMailer、编译的共享库、插件路径与 setuid 程序。

二进制安全

  • 栈与相邻对象覆盖 · 8 个来源，269 个代码块。Brainpan 系列保留偏移、函数指针与多种入口，不能只取最后一份脚本推断全部过程。
  • 格式化字符串、地址泄漏与保护绕过 · 5 个来源，63 个代码块。Echoland 从网络接口恢复 ELF，原脚本包含错误地址与崩溃处理。
  • ROP、SROP、JOP 与系统调用 · 6 个来源，76 个代码块。execve 与 mprotect 两篇实验保留可写区选择、页对齐和 read 输入的先后关系。
  • V8 类型推断与任意读写原语 · 2 个来源，72 个代码块。Math.expm1 题的关键是优化阶段对类型和边界的错误推断。
  • 内核接口、映射与权限原语 · 3 个来源，168 个代码块。RopeTwo 的 ralloc 记录 IOCTL、tty_operations、KASLR、栈迁移与权限恢复。
  • UAF、tcache 与分配器状态 · 3 个来源，98 个代码块。Little Tommy 用 memo 重用已释放账户，字段布局决定覆盖内容。
  • 认证程序逆向与 Salsa20 数据恢复 · 1 个来源，5 个代码块。修改条件跳转可以观察后续代码，真正的输入验证仍要恢复数据关系。

身份与域安全

  • 备份材料、验证流程与密码规则 · 3 个来源，57 个代码块。Delivery 的工单邮箱与 Mattermost 注册流程连接到密码规则。
  • ACL、Shadow Credentials 与 Kerberos 委派 · 3 个来源，130 个代码块。Absolute 的禁用 NTLM、交互登录权限与成员回滚影响每次工具调用。
  • ESC13 组映射与多阶段域权限 · 1 个来源，72 个代码块。Web 入口、认证 Relay 和 Shadow Credentials 分别对应不同执行身份。

云与容器安全
